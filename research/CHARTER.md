## 0. What is being asked

Invent a **ground-up computational primitive** — a state update and a readout, not a re-plumbed
Transformer — that:

| # | Requirement | How it is judged |
|---|---|---|
| R1 | Runs fast on **CPU** | per-token work independent of history length (§3, G3) |
| R2 | **Bounded working RAM**, no growing KV-cache | state bytes are O(1) in sequence length (§3, G2) |
| R3 | **Low training cost**, no massive GPU backprop | closed-form/online/local rule, wall-clock budget (§3, G5) |
| R4 | **Zero capability loss**: full exact recall + smooth compositional reasoning | G1 + G6, on a *declared envelope* (§1) |
| R5 | **Genuinely new**, not a splice of existing papers, not a re-run of a known failure | novelty certificate + pre-registered kill tests (§2, §5) |

## 1. The first honest move: "zero capability loss" needs an envelope

As literally stated — *match an arbitrary large Transformer on all tasks with a bounded-state,
closed-form-trained primitive* — the requirement is not merely hard, it is **arithmetically
impossible**, and a charter that pretends otherwise produces a demo, not a primitive. (§1.1 is a
counting argument, not an opinion.)

So R4 is bound to a **declared capability envelope**, fixed *before* any implementation:

- **E-RECALL**: exact verbatim retrieval over a stream of ≥ 10⁶ tokens, arbitrary query positions,
  and no query seen during learning.
- **E-COMPOSE**: systematic generalization on a *declared* grammar/rule family — held-out
  compositions of seen primitives, where the held-out set is generated by a rule stated in advance
  (so "generalization" cannot be retro-fitted to whatever the model happens to do).
- **E-EDIT**: a fact stated once is correctable without retraining, and the correction does not
  corrupt unrelated facts (this is the failure that kills lookup-table designs).

Outside the envelope the gap is **reported, not hidden**: every result table carries the
same-parameter-count Transformer baseline, so "beats" always has a denominator.

**Refusal clause.** Neither agent may write the words "matches GPT-class reasoning" in a result
until a number on this page supports it. Re-scoping the envelope after seeing results is an
unratified `AMEND` and is void.

### 1.1 Why the literal reading is impossible (state it once, then work)

A state of `W` bits, updated causally by a function of `W` bits and one token, cannot answer
arbitrary content queries over an unbounded stream. Two independent walls:

1. **Pigeonhole.** `n` distinct histories mapping into `2^W` states collide once `n > 2^W`.
   Distinctness is not cosmetic: there exist query sets on colliding histories with different
   correct answers, so at least one history must be answered wrong. Bounded state ⇒ lossless
   unbounded recall is impossible. Exact, no get-out.
2. **Energy/counting.** Answering `q` independent retrieval queries whose answers live in a set of
   size `S` requires ≥ `q·log₂S` bits *somewhere*. If they are not in working RAM, they are in a
   store being addressed — which is fine, but it means the primitive is *state + addressable store*,
   and "zero growth" must be claimed about **working state**, not about the universe.

**Consequence, adopted as a design constraint, not a loophole:**
the primitive is `bounded working state + external store`. R2 is satisfied by holding the *RAM*
constant while a store grows. That is a real and measurement-visible distinction:
a KV-cache Transformer re-reads O(n) bytes **per generated token**; a bounded-state primitive
must read O(1). §3 G2/G3 measure exactly that, and the pre-registered failure mode is
"constant RAM but O(n) reads per token" — that is a Transformer with extra steps and is killed.

## 2. Anti-mashup rule (R5), operationalised

"Not a mashup of existing papers" is a vibe unless it has a test. The test:

**Novelty certificate.** The primitive must be stated in exactly three equations —
(1) `sₜ = F(sₜ₋₁, xₜ)`, (2) `yₜ = G(sₜ, q)`, (3) `θ ← H(θ, sₜ, xₜ, yₜ)` — plus these exhibits:

- **NC-1 (no special case).** Show which existing named mechanism results from deleting each term.
  If deleting *every* term yields a known method, it is a mosaic. At least one term must be
  **load-bearing**: its removal must break G1 or G6, demonstrated by an actual ablation run.
- **NC-2 (failure-mode check).** Name the closest failed/abandoned lineage and state the *specific*
  reason it failed. If the primitive does not mechanically address that reason, it is a re-run.
- **NC-3 (prior-art diff).** A one-page table: closest 6 systems × the 4 axes {bounded RAM,
  exact recall, CPU-forward, closed-form training}. Us being equal on 3 axes and better on 1 is
  fine; equal on all 4 with a different diagram is not.
- **NC-4 (no retrofit).** The mechanism must be justified *before* its benchmark number is known.
  Any mechanism introduced after a failing result must be labelled `post-hoc` and cannot be the
  load-bearing term.

## 3. Gates (numbers, not adjectives)

All measured on CPU-only, single core, no GPU anywhere in the loop. Baselines are reported
alongside every number. Units: G1–G2, G6 exactness in %; G3 ms/token; G4 bytes; G5 seconds.

| Gate | Requirement | Threshold | Fail means |
|---|---|---|---|
| **G1** | exact recall @ 10⁶ tokens, held-out query positions | 100.0% (no tolerance) | not "exact recall" |
| **G2** | working-state bytes, seq 10³ → 10⁶ | ratio ≤ 1.10 (O(1)) | it is a cache |
| **G3** | per-token CPU cost, seq 10³ → 10⁶ | ratio ≤ 1.20 (O(1)) | it is attention |
| **G4** | bytes read per generated token | ≤ 4 KiB, flat in n | it re-reads history |
| **G5** | total training wall-clock on CPU | ≤ 10 minutes to envelope-parity | not "low training cost" |
| **G6** | held-out composition accuracy vs. seen-composition accuracy | gap ≤ 5 points | not "smooth composition" |
| **G7** | E-EDIT: single-fact correction, collateral damage | 0 unrelated facts changed | it is a lookup table |
| **G8** | **calibrated abstention**: on inputs it cannot answer, does it say so? | held-out wrong answers = 0, and every abstention attributable to a named missing structure | it guesses, and a wrong guess is indistinguishable from a right one |

G8 is not decoration. A softmax Transformer has no way to express "I have no basis for this",
so it cannot reach 0 wrong on genuinely unseen compositions at any parameter count. A primitive
that abstains with a *cause* converts silent failure into an enumerable gap — which is what makes
R4 measurable instead of rhetorical. Baseline measured in `bench/RESULTS.md` §D4.

**Pre-registered kill tests.** These falsify the *program*, and are checked before G-gates:

- **K1 (the smoothness wall).** If, for every candidate tested, held-out composition gaps grow
  monotonically with `#primitives`, the primitive is not compositional — it is interpolating, and
  the "smooth reasoning" claim dies. Report the curve.
- **K2 (the exactness wall).** If exactness degrades faster than `log₂ W` bits of state per
  decade of stream, the design is a compressor, not a primitive.
- **K3 (the cheapness wall).** If a closed-form/local rule cannot clear G6 while a same-size
  backprop baseline clears it by > 2× the gap, then "no GPU backprop" and "zero capability loss"
  are mutually exclusive at that scale. **Report this as the headline finding.** It is a result.
  Hiding it is the failure mode this charter exists to prevent.

Both agents must re-read K1–K3 before publishing any result. A program that dies at K3 with a
clean number has produced something true; a program that survives only by moving the envelope has
produced a product.

## 4. The crux (what we are actually trying to break)

Not "attention is slow". The crux is a *tension*:

- **Exactness** wants a representation with no interpolation: discrete, collision-free, closed
  under update (tables, hashes, term algebras).
- **Smooth compositional reasoning** wants continuity: unseen compositions must stay inside the
  representable set with graceful degradation (vector spaces, metrics, gradients).

These are the two sides of the impossible trade, and every failed prior attempt failed by picking
a side and calling the other one "emergent". The research question is therefore:

> **Is there a representation closed under composition whose parameters can also be learned by a
> local rule — i.e. an algebra where "new composition" is a legal element rather than an
> interpolation between neighbours?**

Anything that answers this question *mechanically* is in scope. Anything that only performs well
without answering it is a baseline, not the primitive.

Candidates are **not** chosen in this charter. They go in `research/threads/`, each with a
pre-registered falsifier, and each must survive K1–K3 before earning implementation hours.
agent-b is expected to attack this section first.
